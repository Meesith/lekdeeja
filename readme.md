# เลขทะเบียนมงคล (Lucky License Plate Finder)

เว็บแอป Flask ไฟล์เดียว (`app.py`) สำหรับค้นหาเลขทะเบียนรถที่เหมาะกับเจ้าของ
โดยใช้ศาสตร์ตัวเลข (ทักษา + เลขประจำตัว) วิเคราะห์ร่วมกับ **วันเกิด เดือนเกิด และปีเกิด**
หน้าเว็บใช้ Tailwind CSS ผ่าน CDN

## ความต้องการของระบบ

- Python 3.9 ขึ้นไป
- Flask
- อินเทอร์เน็ต (สำหรับโหลด Tailwind CDN และฟอนต์ Prompt)

## ติดตั้งและรัน

```bash
pip install flask
python app.py
```

เปิดเบราว์เซอร์ไปที่ <http://127.0.0.1:5000>

## วิธีใช้งาน

1. **เลือกวันเกิด** อาทิตย์ถึงเสาร์ หรือพุธกลางคืน (ราหู)
2. **เลือกเดือนเกิด**
3. **กรอกปีเกิด (พ.ศ.)** เช่น `2540` ถ้ากรอกเป็น ค.ศ. ระบบจะแปลงให้อัตโนมัติ
4. กด **ค้นหาเลขมงคลของฉัน**

### ตัวเลือกเพิ่มเติม (ไม่บังคับ)

| ตัวเลือก | ความหมาย |
|---|---|
| จำนวนหลักตัวเลข | 1–4 หลัก (ค่าเริ่มต้น 4) |
| จำนวนผลลัพธ์ | 10 / 20 / 30 / 50 อันดับ |
| อักษรนำ | ใส่ตัวอักษร เช่น `กข` เพื่อแสดงบนป้ายทะเบียน (ไม่มีผลต่อคะแนน) |
| ขึ้นต้นด้วย / ลงท้ายด้วย | กรองเฉพาะเลขที่ขึ้นต้นหรือลงท้ายตามที่ระบุ |
| ต้องมีเลข | เลขทะเบียนต้องมีเลขทุกตัวที่ใส่ |
| ไม่เอาเลข | ตัดเลขทะเบียนที่มีเลขเหล่านี้ออก |
| ตรวจเลขทะเบียนที่มีอยู่ | ใส่เลขทะเบียนปัจจุบันเพื่อดูคะแนนและคำอธิบายละเอียด |
| ตัดเลขกาลกิณีอัตโนมัติ | ไม่แสดงเลขที่ขัดกับดวงวันเกิดของคุณ (เปิดไว้เป็นค่าเริ่มต้น) |

## อ่านผลลัพธ์

- **ดวงตัวเลขของคุณ** – เลขประจำตัว เลขปีเกิด เลขเสริมดวง และเลขกาลกิณีที่ควรเลี่ยง
- **คะแนน 0–100 และเกรด** – มงคลยิ่ง (80+) · ดี (65+) · พอใช้ (50+) · ควรเลี่ยง (ต่ำกว่า 50)
- **ชิปสีของเลขแต่ละตัว** – เขียว/ฟ้า = เสริมดวง, เทา = กลาง, แดง = กาลกิณี
- **ผลรวม** – ผลรวมของเลขทะเบียนที่ลดเหลือหลักเดียว พร้อมบทบาทตามทักษา
- **คู่เลข** – คู่ที่ติดกัน เขียว = มงคล, แดง = ควรระวัง

## หลักการคำนวณโดยย่อ

1. **ทักษา 8 ทิศ** นับจากวันเกิดเป็น บริวาร, อายุ, เดช, ศรี, มูละ, อุตสาหะ, มนตรี, กาลกิณี แล้วแปลงเป็นเลขดาว 1–8
   (อาทิตย์=1, จันทร์=2, อังคาร=3, พุธ=4, พฤหัส=5, ศุกร์=6, เสาร์=7, ราหู=8) เลข 9 = ก้าวหน้า, เลข 0 = กลาง
2. **เลขประจำตัว** = รวม (เลขวัน + เดือน + ผลรวมเลขปี พ.ศ.) จนเหลือหลักเดียว
3. **คะแนน** = ค่าเฉลี่ยเลขแต่ละตัว (40%) + ผลรวมเลขทะเบียน (35%) + คู่เลขติดกัน (25%) แล้วหักคะแนนเมื่อมีเลขกาลกิณี

ปรับสูตรให้ตรงกับตำราที่คุณใช้ได้ที่ค่าคงที่ในไฟล์ `app.py`:
`TAKSA_CYCLE`, `TAKSA_ROLES`, `GOOD_PAIRS`, `BAD_PAIRS`

## API (JSON)

```
GET /api/search?day=2&month=5&year=2540&length=4&limit=10
```

พารามิเตอร์: `day` (1–8), `month` (1–12), `year`, `length`, `limit`, `starts`, `ends`, `must`, `avoid`, `skip_bad` (`1`)

ตัวอย่างผลลัพธ์:

```json
{
  "profile": {"day": "จันทร์", "month": 5, "year": 2540, "life_number": 9, "lucky": [4, 5, 7, 9], "avoid": [1]},
  "results": [{"number": "9999", "score": 92, "grade": "มงคลยิ่ง", "sum": 9}]
}
```

## ข้อควรทราบ

- ผลวิเคราะห์เป็นความเชื่อทางศาสตร์ตัวเลข เพื่อความบันเทิงและเป็นแนวทางประกอบเท่านั้น
- ระบบไม่ได้เชื่อมกับกรมการขนส่งทางบก จึงไม่ทราบว่าเลขใดว่าง ต้องตรวจสอบก่อนประมูลหรือจองทะเบียนจริง
- ยังไม่วิเคราะห์ตัวอักษรไทยของทะเบียน เฉพาะตัวเลขเท่านั้น
